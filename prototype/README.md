# 电机选型工具 — 可交互页面原型

本目录是依据 `doc/requirements.md` 制作的**纯前端交互原型**，用于验证界面结构与交互设计。
不含服务端逻辑，所有计算在浏览器本地完成。

## 运行方式

直接用浏览器打开 `index.html` 即可（无需构建、无需启动服务）。

## 目录结构

```
prototype/
├── index.html          页面骨架（顶栏 / 三列工作区 / 两张曲线图）
├── css/style.css       视觉样式
└── js/
    ├── data.js         示例电机库 + 字段分组（对应需求第 6 章三档字段）
    ├── calc.js         计算内核（对应需求第 4、5、7 章）
    ├── chart.js        Canvas 折线图
    └── app.js          交互逻辑与渲染
```

## 交互演示要点

1. **切换页签**：顶栏左右切换「直线马达 / 旋转马达」，字段与单位整体切换。
2. **点到点 vs 自定义**：切到自定义后，「运动时间」变为可选项；清空时间并填入最大速度与加速度，时间框自动变为只读推算值。
3. **S 曲线**：勾选后可自由填写平滑时间（默认 16 ms）。观察峰值加速度出现「+X%」上抬标记，且理想值单独列出。
   - 反例：把运动时间压到 0.2 s 再填 56 ms，会直接报错并给出「当前工况允许的最大平滑时间」。
4. **边界报错**：点到点模式下填一个很低的「最大速度」上限，会触发红线报错并给出超出百分比。
5. **推荐电机**（第 52 轮更名，取消「推荐 / 全部型号」切换）：
   - 只列通过两条准入的型号，按余量由低到高；达不到下限的型号**不出现**（下限是过滤器）；
   - 勾选结构/冷却是**附加过滤**；列表较高，型号多时可独立滚动；
   - 电机库中含一条刻意缺 `Kth`/`Tmax` 的型号，因判为「信息不全」而天然不进列表。
6. **选定电机**：点候选项或在「选入电机数据」顶部下拉选择后，右侧按样册式单列展示参数（持续/峰值推力、电机常数、推力常数、反电动势常数、连续/峰值电流、电感、绕线电阻、额定/最大功率、线圈重量/长度；旋转页对应力矩、扭力常数、转动惯量等），并展示实际应用值（含电机惯量的重算、线圈温度、所需母线电压、安全系数、供电结论）；力-时间图上叠加电机连续/峰值能力参考线。
7. **曲线管理**：新建 / 删除 / 翻页，对应「项目 → 轴 → 方案」层级。
   - **导出报告会覆盖当前页签下的全部方案**（第 42 轮）：建两条以上再点「导出报告」，可以看到封面目录 + 每条方案各一节、各带自己的两张曲线图；无法计算的方案会被标注原因并跳过正文。
8. **导入参数**：弹窗提供手工录入表单；样册识别标为后续版本。
9. **电机类型（第 38 轮）**：手工录入表单首行是「电机类型」下拉（直线 / 力矩 / 音圈），切换后字段模板整体换套——直线按 AKM30 式、力矩按 ADR110 式、音圈按 AVM 式；「配置」在其下独立保留，仍参与主键。
   - 「配置」是**下拉**（第 39 轮），选项随类型变化：直线 `默认/串联/并联`、力矩 `串联/并联/默认`、音圈 `默认`；型号名 + 配置已存在时拒绝入库。
   - 候选列表混排三种类型，每行前带类型徽标；与当前页签量纲不同的行（如直线页里的力矩电机）灰显「不适用」，不参与判定也不能选入。
   - **筛选 chip 只有结构 / 冷却**（直线页为 无铁芯、有铁芯、普通、水冷、气冷；旋转页为 有铁芯、无铁芯、普通、气冷、水冷），不再出现「直线 / 力矩 / 音圈」类型选项（第 43 轮）。
   - 旋转页的「超声波力矩电机」结构 chip 与中孔「标准 / 特殊」chip 已移除（第 58 轮）；这三个取值仍是型号属性，录入表单与详情展示照旧。
   - **新录入的电机一定会参与判定**（第 44 轮）：准入判定只要求模板上标 `*` 的字段；最高速度未录入时跳过该条准入并在判定依据里注明「未校核」，不再整条判为信息不全。
   - 直线与音圈的「最高速度 @峰值/持续推力」在「准入补充」分组里，样册没有就留空——该型号随之判为信息不全，不臆造数值。
   - 音圈「行程」仅作参数展示；线圈质量按 g 录入、内部换算 kg。
   - **必填清单 = 参与计算的参数（第 48 轮定稿，第 49 轮补充电流）**，通过「删一法」逐参数实测得出：
     - 直线 10 项：持续推力、峰值推力、力常数、反电势常数、相间电阻、**持续电流、峰值电流**、最高线圈温度、热耗散常数、最高母线电压；
     - 音圈 10 项：持续推力、峰值推力、力常数、反电势常数、电阻、**持续电流、峰值电流**、最高线圈温度、热耗散常数、最高电压；
     - 力矩 12 项：持续转矩、峰值转矩、转矩常数、反电势常数、相间电阻、**持续电流、峰值电流**、最高线圈温度、热耗散常数、最高母线电压、最高转速 @峰值/持续转矩。
     - `Icont` / `Ipeak` 实际**不进入任何计算**，但按第 49 轮要求仍为必填（电机核心额定值，缺项即数据不完整）。
   - 改为**选填**的（均不参与任何计算）：`Km`、`L`、`Te`、`Pn`、极数、线圈质量/转动惯量、电磁周期、磁吸力、线圈长度、磁轨质量、行程、铁芯质量、运动间隙、端跳与载荷限值。
   - **电机常数 `Km`** 若未录入，详情表按 `Kt/√(1.5·R_ll)`（三相）或 `Kf/√R`（音圈）自动派生；它**不参与温度与电压计算**。
   - **电感 `L` 不参与温度与电压计算**：理想电感直流稳态不产生损耗，铜损已由 `R25` 计入。
   - **保存即校验（第 41 轮）**：任一 `*` 项为空则拒绝入库，弹窗内吸顶显示缺项清单并标红、聚焦首个缺项；补填时提示实时更新，填齐后自动消失。
   - **必填项前置（第 50 轮）**：表单内必填项连续排在最前、选填项全部尾随，从上往下即「所有必填 → 所有选填」。
   - **冷却条件联动（第 51 轮）**：选出「水冷 / 气冷」时，持续电流、持续热功率、热耗散常数、线圈质量、线圈长度这 5 项的标签会自动从「(自冷)」变为「(水冷)/(气冷)」，已填的数值不受影响。（仅直线模板有此 5 处标注）

### 输入区双列（第 27 轮）

输入区分为 **「用户输入 ｜ 计算结果」** 两列，用来一眼看出每项**实际参与计算的值**：

| 列 | 表现 |
|---|---|
| 用户输入 | 可填；留空显示占位「留空自动」 |
| 计算结果 | 该行实际生效值；由系统算出时标紫 |

- 已填值被计算取代时，左侧标黄 + 提示「输入未生效，实际生效 X」
- 口径未定的项（当前仅旋转页的倾斜角度），右侧显示「待确认」，避免假装参与了计算

**点到点模式下**，「最大速度」「最大加速度」为只读理论值，随距离与时间实时回填；开启 S 曲线时回填的是上抬后的加速度，并在字段下方注明。

## 形状可选后的输入约束（重要）

形状是用户输入，因此「给定 S、T 后仍有几个自由度可用」随形状变化：

| 模式 | 形状 | 求解所需 | 说明 |
|---|---|---|---|
| 点到点 | 梯形（用户选） | 距离 + 时间 | `x = T/3`，加速/匀速/减速各 1/3 |
| 点到点 | 三角形（用户选） | 距离 + 时间 | `x = T/2`，无匀速段；**1:3 比例不适用** |
| 自定义 | **自动判定** | 距离 + 时间 + (加速度 或 速度) | 由加速度优先定形 |
| 自定义 | **自动判定** | 距离 + 加速度 + 速度 | 反算时间 |
| 自定义 | **自动判定** | 距离 + 加速度 | 必为三角形，反算时间 |
| 自定义 | **自动判定** | 距离 + 时间 | 无约束，默认标准梯形 `x = T/3` |
| 自定义 | — | 距离 + 速度（仅） | 报错：无法定位形 |

**自定义模式的形状不再由用户选择**（第 26 轮），而是由求解结果自动判定：

```
x < T/2  → 梯形（有匀速段）
x = T/2  → 三角形（无匀速段）
```

判定优先级：**加速度上限 > 速度上限 > 默认 1:3**。因为同一时间内加速度用得越足、峰值速度越低，所以优先用加速度定形。

冲突一律显式报错，不做静默降级：

- `aMax < 4S/T²` → 低于三角形所需的加速度下限，只能延长 T；
- `vMax < S/T` → 仅匀速段就超过总时间；
- 加速度定出的峰值速度 `> vMax` → 两个上限互相矛盾。

> 之所以必须这样，是因为梯形与三角形在 S、T 固定时的**峰值速度需求不同**：
> 三角形 `v = 2S/T` 是下限，梯形 `v = S/(T−x) < 2S/T` 但 `a` 更高。
> 想「又低速度又低加速度」在 S、T 固定时不存在，只能延长时间。
