### 4.4 口径类（易混淆，须严格区分）

| # | 口径 | 说明 |
|---|---|---|

| CAL-2 | **理论结果不含电机** | `theoretical` 只随输入变；唯一例外是安全余量卡片取 `applied.safetyPercent` |
| CAL-3 | **不叠加电机质量/惯量** | 用户填的负载即计算口径（第 45 轮） |
| CAL-4 | **RMS 分段近似** | 三段常数力 + 停顿为 0，jerk 斜坡不单独积分 |
| CAL-5 | **旋转页轴承角不参与计算** | 仅记录，默认 0° |
| CAL-6 | **旋转摩擦力矩恒为正，下限 0** | 计入 `T = J·α + T_f` |
| CAL-7 | **前端只做输入规整** | 钳制/留空自动/`factor` 换算/显示格式化不算公式（D18） |
| CAL-8 | **样册采集口径：不采集「最高线圈温度」** | 导入采集清单（Excel `参数汇总`）里只要选型用得到的项，`Tmax` / 含「线圈温度」的行在识别阶段剔除（`LayoutRules.EXCLUDED_PARAM_*`，06 §5 ⑦″）。**电机库字段 `t_max` 不删**（手工录入仍可填）。~~代价是该电机 `t_max` 留空 → 不做热校核~~ —— 见 CAL-11：缺省按 100 °C 补，热校核照常进行 |
| CAL-9 | **冷却变体拆成独立型号** | 参数名里带「气冷/水冷」标注的行（含同义词与英文写法）按冷却方式拆成 `-A`/`-W` 型号（06 §7.1）；不带标注的通用参数各型号共用，某型号缺某项留空、不借用；**没有自冷数据不出基型**，型号已带 `-W-`/`-A-` 段不再重复追加。入库也是各自一台电机，冷却字段跟随型号（`-A → 气冷`、`-W → 水冷`、基型 → `普通`）。实现：`CoolingVariants` |
| CAL-10 | **冷却变体按列判定，样册没值不新增型号** | 一张表并排多个型号时，某列的气冷/水冷行写成 `-`/`—` 就是「这个型号不做那种冷却」，**不生成该变体型号**；只在部分列有值就只投影这些列（值列重新编号）。判据只看本变体的行，通用行（峰值电流等）不算证据。实现：`CoolingVariants.partOf`（06 §7.1 第 5 条） |
| CAL-11 | **最高线圈温度缺省 100 °C** | 样册不采集（CAL-8），但热校核离不开：入库时 `tMax` 缺值补 100（`CatalogRowMapper`，notes 留痕），计算时再兜一层缺省（`AppliedCalculator`，`MotorCatalogTemplates.DEFAULT_MAX_COIL_TEMP` 单一来源）。线圈温度的迭代本身**只依赖 R25 / Kth / 实际电流**，不依赖 `Tmax`——`Tmax` 只用于允许电流与超温判定 |
