## 1. 范围与目标

把「样册 PDF/图片 → 草稿 → 人工核对 → 入库」固化为一条**绝不静默写库**的流水线（需求 6.4）：

```
上传（PDF/图片）→ 页面登记 → 页面解析 → 字段映射 → 草稿（含来源页标注）
                                        ↓
              逐条人工编辑/校验 → 勾选批量提交 → 复用 C3 逐条入库
```

**明确不做**：区域框选 UI、批量导入导出、删除已入库电机、自动覆盖同名电机。

## 2. 职责边界（延续 package-info 裁定）

| 项 | 规则 |
|---|---|
| 存储 | 任务与草稿只存 `%APPDATA%\MotorSizer\imports\{jobId}\job.json`，**不落数据库**；原始上传文件存同目录 `source\` |
| 写库 | 唯一入口 = S1 保存用例（`MotorService.create`，复用 C3 校验与事务）；识别模块不直接写 Mapper |
| 计算边界 | 不触碰 K1/K3/S3/S4；字段 schema（key/label/unit/factor/required）全部来自 K2（A1 模板） |
| 单位 | 样册原始值按 K2 `factor` 换算为内部单位后入草稿 `spec`；原始值 + 原始单位存 `rawFields` 供核对 |
| 主键 | 草稿不占用主键；提交时才检查 `型号名 + 配置名` 唯一性（MOTOR_DUPLICATE 逐条回报） |

## 3. 任务状态机

```
UPLOADED ──解析全部/部分页面──► PARSED ──提交全部草稿──► COMMITTED
   │                            │
   └──────────── 取消/清理 ──────┴──► CANCELLED
```

- `UPLOADED`：文件已登记、页面清单已生成，尚未解析。
- `PARSED`：至少一页解析完成（页面级状态独立，见 §4）。
- `COMMITTED`：勾选草稿全部提交完毕（含部分失败：逐条结果见响应，任务保留供修正重提）。
- `CANCELLED`：用户删除任务（磁盘目录一并清理）。

**并发与生命周期**：单用户本地工具，v1 不做任务队列；解析接口同步执行（单页百行级文本，毫秒~秒级）。任务保留 30 天，**启动时惰性清理**过期目录（Q3 裁定）；I2 列表展示「剩余 X 天」。

## 4. 数据结构（job.json）

```jsonc
{
  "jobId": "20261119-001",            // 日期 + 当日序号，URL 安全
  "status": "PARSED",
  "createdAt": "2026-11-19T00:00:00Z",
  "files": [                           // 上传文件登记
    { "fileId": "f1", "name": "ADR110.pdf", "kind": "pdf", "pages": 4 }
  ],
  "pages": [                           // 页面 = 解析单元（一页 → N 草稿）
    {
      "pageId": "f1p2", "fileId": "f1", "pageNumber": 2,
      "status": "RECOGNIZED",          // PENDING / RECOGNIZED / EMPTY / OCR_REQUIRED / FAILED
      "message": null,                 // FAILED/OCR_REQUIRED 时的人类可读原因
      "textLineCount": 38              // 提取到的文本行数（核对参考）
    }
  ],
  "drafts": [                          // 草稿：结构对齐 MotorUpsertRequest + 识别元数据
    {
      "draftId": "d1",
      "pageId": "f1p2",                // 来源页标注（需求 6.4）
      "sourcePage": "第 2 页",
      "confidence": 0.86,              // 命中字段数 / 应命中字段数
      "request": { /* MotorUpsertRequest 全量（entryMethod=识别草稿） */ },
      "rawFields": { "R25": { "value": "4.90", "unit": "Ω", "text": "R25(相间) 4.90 Ω" } },
      "issues": [ { "field": "iCont", "reason": "样册值为 3.2，超出业务上限" } ],
      "checked": true                  // 批量提交的勾选态
    }
  ]
}
```

- `issues` 由**客户端调用 I11（校验）或提交时服务端 C3 校验**回填，草稿本身不重复实现校验规则（单一来源）。
- `OCR_REQUIRED`：无文本层的扫描 PDF / 图片页——P0 阶段的显式状态，P1 接入 Tess4J 后消解。

## 5. 识别流水线（页面解析内部）

```
① 文本提取   PDF→PDFBox 文本层（带坐标）；图片/扫描页→OCR（P1，Tess4J 可插拔接口）
② 结构判定   先判页面是「单配置行式」还是「多列对照表」：
             - 单配置行式：按坐标 y 容差聚成文本行；按 x 间距切「参数名+值」两段
             - 多列对照表（Q1 裁定支持）：识别表头行（配置名：默认/串联/并联…），
               后续每行 = 一个参数名 + 按列对齐的多组值；列对齐用 x 坐标聚类
③ 字段映射   K2 label 及别名字典（§6）→ key；数值规整（千分位逗号、全角、单位词尾）
④ 单位换算   原始值 × factor → 内部单位（音圈 g→kg 等）；原始值留 rawFields
⑤ 草稿切分   单配置行式：以「型号名行」为界切分型号段，一段一草稿；
             多列对照表：表头每个配置名一列，每行参数对齐后按列组装，
             一张表生成 N（配置数）× M（型号段数）条草稿（一页 N×M 条，需求 6.4）
⑥ 置信度     mapped / (mapped + requiredMissing)；来源文本逐字段留存
```

**多列对照表的支持边界**（Q1 裁定）：表头需为「配置名」且与 K2 `configs` 取值（默认/串联/并联）可匹配；表头识别失败或列对齐失败时，该页降级为 `EMPTY` 并提示「表头无法识别，请改用手工录入」，不强行猜测。

## 6. 字段映射字典

- 一级匹配：K2 `label` 去空白/去 `({cool})`/去 `@100°C` 测试条件后缀后全等。
- 二级匹配：别名表（样册常见变体），如 `R25 ↔ 相间电阻/线间电阻`、`Kth ↔ 热耗散常数/散热常数`、`Kt ↔ 力矩常数`、`Icont ↔ 持续电流/连续电流`、`vmax ↔ 最高速度/最大转速`。
- **别名字典随 K2 模板下发**（Q2 裁定）：在 `MotorField` / `FieldDto` 增加 `aliases: List<String>` 字段，A1 响应携带；向后兼容（前端旧版忽略该字段）。K2 是字段字典唯一来源（C-B 不变量），别名属字段元数据，归 domain 维护。
- 电机类型判定：页面内命中的字段集合与三套模板的必填集求交，取最大者；三者皆低于阈值 → 页面 `EMPTY`。

## 7. 接口清单（I1–I13）

统一信封、错误码前缀 `IMPORT_`、路径小写名词（遵循 api-rules 2.x / 04 §1–2）。上传走 `multipart/form-data`（上限已按 application.yml：单文件 50MB、单请求 60MB）。

| # | 方法与路径 | 职责 | 要点 |
|---|---|---|---|
| I1 | `POST /api/imports` | 创建任务（上传 1..n 个 PDF/图片） | 返回 jobId + 页面清单；文件落 `imports\{jobId}\source\`；类型/大小校验 |
| I2 | `GET /api/imports` | 任务列表 | 倒序；仅摘要（jobId/状态/文件数/草稿数/时间），不回传正文 |
| I3 | `GET /api/imports/{jobId}` | 任务详情 | 含 pages 与 drafts 摘要；404 = IMPORT_JOB_NOT_FOUND |
| I4 | `DELETE /api/imports/{jobId}` | 取消/清理任务 | 删磁盘目录 + 状态置 CANCELLED（CANCELLED 后目录即删，仅返回体留痕） |
| I5 | `GET /api/imports/{jobId}/pages` | 页面列表 | 每页：pageId/状态/来源文件/页码/文本行数 |
| I6 | `GET /api/imports/{jobId}/pages/{pageId}/text` | 页面提取文本（行数组） | 核对用；OCR_REQUIRED 页返回提示而非文本 |
| I7 | `POST /api/imports/{jobId}/pages/{pageId}/recognize` | 解析单页 → 生成/重建草稿 | 同步；幂等（重跑先删该页旧草稿）；返回草稿摘要 |
| I8 | `GET /api/imports/{jobId}/drafts` | 草稿列表（含来源页、置信度、issues） | 支持按 pageId 过滤 |
| I9 | `PUT /api/imports/{jobId}/drafts/{draftId}` | 编辑草稿 | 请求体 = MotorUpsertRequest 子集（整体替换草稿的 request）；编辑即重算 issues（调 C3 校验，不写库） |
| I10 | `DELETE /api/imports/{jobId}/drafts/{draftId}` | 删除单条草稿 | 草稿非业务数据，允许删除（与「电机库不提供 DELETE」不冲突） |
| I11 | `POST /api/imports/{jobId}/drafts/{draftId}/validate` | 单条校验 | 复用 MotorSpecValidator；返回通过/字段错误列表，不写库 |
| I12 | `POST /api/imports/{jobId}/commit` | 批量提交勾选草稿 | **逐条独立事务**（Q4 裁定）：逐条调 MotorService.create，每条独立事务；返回逐条 `{draftId, ok, motorId?, error?}`；已成功条目不因其他条目失败而回滚，失败项标 issues 供修正后重提（重提只提交失败项，不重复写已成功项） |
| I13 | `POST /api/imports/{jobId}/drafts/{draftId}/checked` | 勾选/取消勾选 | body `{checked: bool}`；I12 只提交勾选项 |

### 7.1 错误码（新增，前缀分段规则 04 §2.3）

| 码 | HTTP | 含义 |
|---|---|---|
| IMPORT_JOB_NOT_FOUND | 404 | 任务不存在或已清理 |
| IMPORT_PAGE_NOT_FOUND | 404 | 页面不存在 |
| IMPORT_DRAFT_NOT_FOUND | 404 | 草稿不存在 |
| IMPORT_FILE_REJECTED | 400 | 文件类型/大小/数量不合法（errors[].field 指明文件名） |
| IMPORT_OCR_REQUIRED | 400 | 目标页无文本层且 OCR 未安装（P0）；提示安装组件（P1 后仅内部使用） |
| IMPORT_NOTHING_TO_COMMIT | 400 | 没有勾选任何草稿 |
| IMPORT_PARSE_FAILED | 200 + data.message | 页面解析失败按业务分支返回（对齐 API-4 口径：状态 FAILED + 原因，不算协议错误） |

## 9. 前端（M-IMPORT，三步向导）

顶部「导入电机参数」弹窗通道 2 按钮**从禁用占位改为打开向导**（M10 对接点已留）。

| 步 | 内容 |
|---|---|
| 1 上传 | 拖拽/选择 PDF/图片（多选）；成功后展示文件与页面清单 |
| 2 解析核对 | 页面卡片：状态徽标 + 「解析」按钮；解析后展示草稿摘要（型号/配置/置信度/issues 数）；**置信度 < 0.6 标红提醒**（Q5 裁定，仅提醒不阻断提交） |
| 3 草稿提交 | 表格逐条编辑（行内编辑 spec 字段，来源页只读标注）、单条校验、勾选、批量提交；逐条结果回显，失败项可改后重提 |

## 10. 裁定记录（2026-11-19，五项全部定稿）

| # | 问题 | 裁定 | 理由摘要 |
|---|---|---|---|
| Q1 | 多列对照表排版是否支持 | **支持** | 表头识别配置名 + 列对齐 + 一行多草稿；表头识别失败降级 EMPTY。开发量 +30%~40%，用户接受 |
| Q2 | 别名字典位置 | **A1 模板下发，放 domain** | K2 是字段字典唯一来源（C-B 不变量），别名属字段元数据；`MotorField`/`FieldDto` 加 `aliases`，向后兼容 |
| Q3 | 过期任务清理 | **30 天惰性清理** | 启动时扫一次 imports 目录；I2 列表显示剩余天数；避免临时 PDF 无限占用 %APPDATA% |
| Q4 | I12 部分失败语义 | **逐条独立事务** | 已成功不回滚，失败项标 issues 重提；与主键粒度（型号名+配置名）匹配 |
| Q5 | 置信度标红阈值 | **0.6，仅提醒不阻断** | 低于 0.6 通常意味型号段识别错或字段错位，提醒重点核对；不阻断因必填项可手工补填后再提交 |
