## 1. 项目概述

### 1.1 目标

开发一款**本地桌面应用**，把资深电机选型工程师在 Excel 与厂商样册之间手工计算的过程标准化：

> 工况输入 → 规划运动曲线 → 求理论力/力矩 → 从电机库筛选候选型号 → 选定型号 → 计算实际应用值（含热与母线电压校核）→ 输出曲线与选型报告

### 1.2 电机类型范围

**计算侧只有两种运动形式**（第 38 轮把「电机类型」细化为三种，音圈并入直线运动）：

| 电机类型 | 运动形式 | 输入负载物理量 | 输出量 |
|---|---|---|---|
| 直线 | 直线运动 | 总移动质量 (kg) | 持续推力 / 峰值推力 (N) |
| 音圈 | 直线运动（短行程） | 总移动质量 (kg) | 持续推力 / 峰值推力 (N) |
| 力矩（旋转） | 旋转 | 负载惯量 (kg·m²) | 连续力矩 / 峰值力矩 (N·m) |

两种运动形式计算结构同构（`m ↔ J`、`a ↔ α`、`F ↔ T`），共用同一套内核与判定规则。音圈与直流的差别只在**参数表结构**（多「行程」、无转速上限字段）与**行程不参与判定**，计算内核完全复用。

### 1.3 典型使用场景

| 场景 | 说明 |
|---|---|
| 售前快速选型 | 客户给出距离/时间/负载，短时间内算出所需能力并给出候选型号 |
| 同轴多方案对比 | 同一轴下并存多条方案，改变节拍或电机，翻页对比后择一采用 |
| 厂商参数库维护 | 把样册参数录入库中，后续反复复用 |
| 交付文档 | 导出工程文件与 PDF 报告，作为选型依据交付客户或存档 |

### 1.4 使用环境

- 单用户离线桌面应用，不依赖网络。
- 电机参数来源为厂商样册，由用户自行整理入库。

### 4.2 两种运动模式

#### FR-MOT-01 点到点模式

- `T` 指运动段时间，**不含停顿时间**；`总循环周期 = T + 停顿时间`。
- 闭式公式（S 曲线关闭时）随选定的曲线形状而变：

**梯形（默认）** —— 加速、匀速、减速**各占 T 的 1/3**
**输入区双列（第 27 轮）**：输入区改为「用户输入 | 计算结果」双列，见 8.2 节。

| 列 | 内容 |
|---|---|
| 用户输入 | 用户填写的值；留空时显示占位「留空自动」 |
| 计算结果 | **该项实际参与计算的值**；留空项由系统算出时以紫色显示 |

- 已填值被计算取代时（如输入的速度上限高于理论峰值），左侧标黄并提示「输入未生效，实际生效 X」。
- 口径未定、暂不参与计算的项（当前为倾斜角度），右侧显示「待确认」。

### 4.2 两种运动模式

#### FR-MOT-01 点到点模式


- **`最大速度` 与 `最大加速度` 在点到点模式下不是输入项**：二者由「距离 + 时间」算出，输入区以**只读、不可填写**的形式自动回填理论值（第 25 轮变更）。
  - 因此原「用 v_max / a_max 做红线校核」的规则在点到点模式下**取消**（已无输入可比对）；电机能力上限由准入条件②（峰值速度 ≤ 电机最高转速）兜底。
  - S 曲线开启时，回填的 `最大加速度` 为**上抬后**的理论值，并在字段下方注明「已含 S 曲线上抬」。

#### FR-MOT-02 自定义模式

- **距离/角度必填**（它是选型目的）。
- **不选择曲线形状**：形状由求解结果自动判定（第 26 轮变更），见 FR-MOT-03。
- 时间、最大速度、最大加速度三者**填得越多，可反算的其余参数越多**；留空项由系统算出并以紫色标注，用户可随时填写覆盖。

**A. 已给运动时间 T**

| 已填 | 求解 | 形状 |
|---|---|---|
| `T + a_max` | `a·x(T−x) = S` 取较小根 → `x` | `x < T/2` 梯形；`x = T/2` 三角形 |
| `T + v_max` | `x = T − S/v_max` | 同上 |
| `T + a_max + v_max` | 由 `a` 定 `x`，再用 `v_max` 校验 | 冲突则报错 |
| 仅 `T` | 无约束，按标准梯形 `x = T/3` | 梯形 |

**B. 未给运动时间**

| 已填 | 求解 |
|---|---|
| `a_max + v_max` | 先试 `x = v_max/a_max`，`T = S/v_max + x`；若 `x > T/2` 则退化为三角形 |
| 仅 `a_max` | 三角形：`x = √(S/a_max)`，`T = 2x`，`v = √(S·a_max)` |
| 仅 `v_max` | **报错**：速度只约束匀速段，无法定位形与时间 |
| 全空 | **报错**，提示至少给一项 |

**C. 冲突一律显式报错**

| 情形 | 报错要点 |
|---|---|
| `a_max < 4S/T²` | 低于三角形所需加速度下限，只能延长 T 或提高加速度 |
| `v_max < S/T` | 仅匀速段就超过总时间，无法完成 |
| `a` 定出的峰值速度 > `v_max` | 两个上限互相矛盾，请放宽其一 |

- 自定义模式下，加速时间由求解结果决定，不再固定为 T/3。

#### FR-MOT-03 曲线形状（梯形 / 三角形）

- **两种模式的规则不同**：

| 模式 | 形状来源 | 说明 |
|---|---|---|
| 点到点 | **用户选定**（单选钮保留） | 梯形 `x = T/3`；三角形 `x = T/2` |
| 自定义 | **系统自动判定** | 不出现形状选择；`x < T/2` → 梯形，`x = T/2` → 三角形，结果区显示判定结果 |

- 原型「三角形旁的 100 %」**作废**。

```
x = 加速段时间，取值 (0, T/2]
  梯形：    0 < x < T/2，存在匀速段
  三角形：  x = T/2，匀速段为 0
```

> **数学事实（须向用户说明）**：在 S、T 均固定时，三角形给出 `a` 的下限 `4S/T²` 与 `v` 的上限 `2S/T`；
> 梯形给出更低的 `v` 与更高的 `a`。因此「同时降低峰值速度与峰值加速度」在 S、T 固定下无解，唯一出路是延长运动时间。
> 这也是自定义模式**优先用加速度上限定形**的原因：加速度用得越足，峰值速度越低。

### 4.3 S 曲线（平滑）

- `τ` 定义为**单侧爬升时间**（加速度从 0 升至 `a_peak` 所需时间）；一个加速段含两端各 τ 的 jerk 斜坡，总过渡 2τ。
- **`v_peak` 不因平滑而改变**（对称平滑的面积亏损由后段补偿），只有 `a_peak` 上抬：

```
v_peak = S / (T − x)        ← 与 τ 无关
a_peak = v_peak / (x − τ)   ← 分母变小，故上抬
```

- 可行条件：`x ≥ 2τ`。点到点梯形即 **T ≥ 6τ**；点到点三角形为 **T ≥ 4τ**；不满足则**不放行**，报错并给出「当前工况允许的最大平滑时间 X ms」。
- 取值：勾选 S 曲线后**自由填写平滑时间（ms）**，默认 16 ms；未勾选即关闭（第 30 轮取消 4/16/56 ms 预设档）。
- 上抬后的 `a_peak`、`v_peak` 与 `a_max`、`v_max` 做红线判定；结果区并列显示「平滑前 / 平滑后 / 上抬 %」。
- ≥ 力-时间图在 jerk 斜坡段需加密采样。

**不采用的处理方式**：自动延长 T；仅做图表圆角美化而不参与计算；自动降档。

## 5. 计算模型

### 5.1 力 / 力矩

```
直线：F = m·a + F_res + m·g·sinθ
旋转：T = J·α + T_f               （纯回转直驱，无传动链、无重力项）
```

**重力分量（仅直线，第 28 轮确认）**

| 项 | 口径 |
|---|---|
| 大小 | `m·g·sinθ`，`g = 9.81 m/s²`，θ 为**带方向**的倾斜角度（第 29 轮） |
| θ = 90° | 垂直向上，重力阻碍，**推力需求增加**：`F = m·a + F_res + G` |
| θ = 270° | 垂直向下，重力助动，**推力需求减小**：`F = m·a + F_res − G` |
| 任意 θ | 按 `sinθ` 自动带符号；手动改角度后按 sin 正负回写方向单选 |
| 方向 上/下 | 仅作快捷设定：选「上」→ θ=90°；选「下」→ θ=270° |
| θ = 0 / 180 | 水平，重力项为 0 |
| 旋转电机 | **无重力项**（纯回转模型无质量与质心偏距输入） |

- **默认值（第 45 轮）**：新建方案时倾斜角 `θ = 0°`（水平、无重力分量），与参考选型软件一致；垂直工况由用户手改为 90° / 270°。

**三段推力与循环 RMS**

```
加速段： F_acc  = m·a + F_res + G
匀速段： F_cru  = |F_res + G|
减速段： F_dec  = |−m·a + F_res + G|
持续需求：F_rms = √[ (F_acc²·t_a + F_cru²·t_c + F_dec²·t_d) / (t_a + t_c + t_d + t_dwell) ]
```

> 已用原型软件的一组参数校验：`m=8 kg, S=1 m, T=1 s, θ=90°, 方向=上, F_res=0`
> → 峰值 `114.480 N`、持续 `83.804 N`，与本产品计算结果**逐位一致**。

- 旋转电机采用**纯回转直驱模型**：无传动链实体、无速比、无导程、无传动件惯量；负载惯量按「已折算到电机轴」的口径由用户直接填写。

### 5.2 两阶段数据流

| 阶段 | 计算内容 | 是否依赖所选电机 |
|---|---|---|
| 理论结果 | 持续推力、峰值推力、最大加速度、最大速度、总循环周期（**5 项纯理论**）；外加「安全余量」1 项，该项**依赖所选电机**，未选时为「—」（第 60 轮） | **否**（前 5 项），数值稳定，用于候选筛选 |
| 电机实际应用值 | 线圈温度、连续电流、峰值电流、直流母线电压、安全系数、持续/峰值力负载系数（7 项） | 是，**按用户填写的负载直接重算** |

- **不叠加电机自身质量/惯量（第 45 轮）**：`F = m·a + F_res + G` 中的 `m` 就是用户填写的「总移动质量 / 负载惯量」，
  不再加上 `moverMass` / `J`。这样输入与输出一一对应、可复算，也与参考选型软件一致（实测电流逐项吻合）。
  - 电机线圈质量/转动惯量仍入库，仅作参数展示。
- 因两阶段解耦，**求解器不与电机耦合**，不存在迭代求解或「换大电机反而不达标」的重算循环。

### 5.3 热模型（仅作用于持续侧）

峰值工况为瞬态，样册无热时间常数/热容，**峰值不做热校核**；峰值只受电气限值 `峰值电流` 约束。

```
R_hot   = R25 × (1 + α×(Tmax − 25)),  α = 0.00393 /K（铜）
I_allow = √( Kth×(Tmax − T_amb) / (1.5×R_hot) )
T_coil  = T_amb + 1.5×I_rms²×R_hot / Kth
判定：I_rms_需求 ≤ I_allow → 通过
```

- 系数 `1.5` 对应样册 `R25` 为**相间电阻**（已确认），三相铜损 = 1.5·I_rms²·R_ll。
- `R_hot` 与 `T_coil` 相互依赖，按一次迭代收敛。
- `Tmax` 按型号入库，不写死为 100 °C。
- **自洽性验证**（ADR110-B136 串联：R25=4.90 Ω、Kth=1.1 W/°C、Tmax=100 °C）：环境 22.5 °C 时 `I_allow = 2.993 Arms`，与样册「连续电流 3.0 Arms @100°C」吻合。说明样册额定值隐含环境约 22.5 °C，这也是 `环境温度` 默认值 22 °C 的来源。
- **`环境温度` 是参与计算的输入**（非记录字段），默认 22 °C。

### 5.4 所需电压（计算输出，非用户输入）

```
U = Ke·v + I_pk·R_hot            ← 报出相电压峰值，不再 √3 折算
R_hot = R25 × (1 + 0.00393×(T_coil − 25))
```

- 在**加速终点**（峰值电流）与**匀速段**（峰值速度）两个工作点分别求值，取较大者。
- **第 45 轮口径变更**：原 `U_dc = √3·U_ph` 的 SVPWM 折算**作废**，直接报相电压峰值，以与参考选型软件对齐（实测偏差 < 1%）。
  - 电流取**真实峰值电流** `I_pk = √2·I_rms`（电压的约束意义是要能逼出峰值电流）；
  - 电阻取**线圈温度下的热态值** `R_hot`（用冷态 `R25` 会低估压降）。
- **不含电感动态压降**（它依赖采样步长假设，会破坏可复算性）。
- `Kt` 按 **RMS 力矩常数**处理，故 `I_rms = T/Kt`。
- 电压**不进入推荐准入条件**；与样册 `Ubus` 的比对仅在 `U_req > Ubus` 的极端情形直接标红。

## 7. 候选筛选与推荐

### 7.1 准入条件（两条，缺一不可）

```
① 电机连续能力 ≥ 理论连续需求 × (1 + 下限%)   AND
   电机峰值能力 ≥ 理论峰值需求 × (1 + 下限%)
② v_peak ≤ 最高转速@峰值转矩   AND   v_peak ≤ 最高转速@持续转矩
```

- 按样册数值，峰值侧转速限制通常起决定作用（1000 rpm < 2000 rpm），但两条**都要判定，不做化简**。

### 7.2 安全余量

| 项 | 语义 |
|---|---|
| 下限（默认 30 %） | **硬红线**：达不到下限即不进入推荐列表（第 52 轮，改为过滤器） |
| 上限（默认 300 %，可勾选关闭） | **软警告**：「余量过大」，不阻断 |
| 安全系数 %（实际应用值区） | **余量口径（第 45 轮）**：`(电机连续能力 − 实际持续需求) / 实际持续需求 × 100%` |
| 持续/峰值力（矩）负载系数 % | **占用口径**：`实际需求 / 电机能力 × 100%` |
